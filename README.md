# 弹幕姬

弹幕姬是一款开源的 Windows B站直播弹幕悬浮工具。

它只接收直播弹幕，不加载直播画面。你可以让浏览器在后台播放声音，同时将弹幕以透明、置顶的方式显示在桌面、网页、视频或其他普通窗口之上。

> 当前处于早期开发阶段，仅支持 B站直播。暂不支持独占全屏游戏。

## 功能

- 输入 B站直播间链接或房间号即可连接
- 弹幕在指定悬浮区域内从右向左滚动
- 支持一键开启或关闭弹幕显示，关闭期间仍保存历史且不会补播
- 透明置顶、鼠标穿透和全局快捷键
- 自由移动和调整悬浮区域大小
- 支持最小化到托盘以及最大化/还原显示区域
- 字号支持小、中、大三档
- 速度支持慢、中、快三档
- 弹幕显示区域支持窗口高度的 10%、25%、50%、75% 和 100%
- 背景透明度支持 0%～100%，弹幕透明度支持 10%～100%
- 滚动区域不显示用户名，历史记录保留用户名
- 支持 B站整条表情弹幕，加载失败时显示原始文本
- 标准 Unicode Emoji 使用本机 Windows `Segoe UI Emoji` 彩色字体渲染
- 屏蔽词自动忽略空格、常见标点和大小写
- 可从历史记录直接屏蔽某条弹幕内容或完整用户名
- 按弹幕正文、用户名或直播间搜索历史
- 历史默认保留 30 天，可选 7/30/90 天或永久，并可查看占用、清理或清空
- 断线自动重连，设置自动保存
- B站二维码登录，登录凭据使用 Windows 当前用户加密保存

## 实时弹幕策略

固定大小的显示区域无法在高峰期同时满足“全部显示、不重叠、零延迟”。弹幕姬采用实时优先策略：

1. 所有收到的原始弹幕立即写入本地历史记录。
2. 重复内容在短时间内自动合并，避免刷屏。
3. 滚动速度始终保持用户选择的档位，不因弹幕量或界面操作自动加速。
4. 等待超过设定新鲜度的弹幕不再进入滚动区域，但仍可在历史中搜索。

主窗口会显示收到、滚动、合并及高峰跳过的数量。新鲜度和重复合并窗口可在控制中心调整。

## 使用方法

1. 下载完整发布包，并保持 EXE 与包内的 `e_sqlite3.dll`、`libSkiaSharp.dll`、`libHarfBuzzSharp.dll` 位于同一目录。
2. 双击运行程序。
3. 输入 B站直播间链接或数字房间号，点击“连接”。
4. 拖动窗口调整位置，拖动右下角调整显示区域大小。
5. 设置字号、速度及透明度后，点击“锁定”开启鼠标穿透。
6. 点击“功能”或右键托盘图标，可打开平台账号、屏蔽词、历史搜索和实时策略设置。

关闭主窗口只会将程序收进系统托盘。需要完全退出时，请右键托盘图标并选择“退出”。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + D` | 显示或隐藏悬浮窗 |
| `Ctrl + Alt + L` | 锁定或解锁悬浮窗 |

鼠标穿透后无法直接点击窗口，请使用 `Ctrl + Alt + L` 解锁。

## 本地数据与隐私

弹幕姬不会将历史记录或设置上传到第三方服务器。

本地数据默认保存在：

```text
%LOCALAPPDATA%\LiveDanmakuOverlay\
├── history.db
├── accounts\bilibili.dat
└── settings.json
```

- `history.db`：SQLite 弹幕历史数据库，包含时间、直播间、用户名、正文及屏蔽状态。
- `settings.json`：窗口位置、显示选项、内容屏蔽词、用户黑名单和实时策略。字号、速度及透明度调整后会立即保存。
- `accounts\bilibili.dat`：可选的 B站登录凭据，仅能由当前 Windows 用户在本机解密。

B站接口本身仍受 B站服务条款、内容规则和接口变更影响。

彩色 Unicode Emoji 在本机渲染并缓存，不会请求第三方 Emoji 图片服务。

未登录连接可能只能收到被 B站脱敏为 `***` 的昵称。可在“功能 → 平台账号”中使用哔哩哔哩 App 扫码登录；登录只影响之后新收到的弹幕，无法还原历史中已经脱敏的用户名。

程序启动时会删除超过保留期限的记录。控制中心可执行“立即清理”并压缩数据库以释放磁盘空间；“清空全部历史”需要二次确认。

## 当前限制

- 仅支持 Windows 10/11 x64。
- 仅支持 B站直播弹幕。
- 支持桌面应用、窗口化和无边框全屏；暂不支持独占全屏游戏。
- 当前仅支持整条 B站表情弹幕，尚未替换普通文本中混排的多个小表情。
- 直播协议或风控规则变化后，可能需要更新客户端。
- 透明 WPF 窗口在部分显卡或系统环境中可能出现动画性能差异。

## 从源码构建

开发环境：

- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)

```powershell
git clone https://github.com/hitoriray/LiveDanmakuOverlay.git
cd LiveDanmakuOverlay
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

发布结果位于 `publish` 目录。SQLite 和 Windows 彩色 Emoji 渲染使用原生运行库，请分发整个 `publish` 目录，不要只复制 EXE。

## 测试

项目包含一个联网与压力冒烟测试：

```powershell
dotnet run --project .\SmokeTest\SmokeTest.csproj -c Release -- 直播间房间号
```

测试会连接 B站弹幕服务器，并验证高峰实时调度、屏蔽词和历史搜索功能。
