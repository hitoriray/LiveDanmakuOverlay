# 直播弹幕悬浮窗（第一阶段）

一个只接收 B站直播弹幕、不加载直播画面的 Windows 透明悬浮窗。弹幕正文（不含用户名）会像直播播放器一样，限制在悬浮窗内部从右向左滚动。

## 使用

1. 运行程序，输入 B站直播间链接或数字房间号。
2. 点击“连接”。浏览器可以最小化并继续播放直播声音。
3. 拖动窗口移动位置，拖动右下角手柄调整显示区域大小；还可调整字号、滚动速度、背景透明度和弹幕透明度。
4. 点击“锁定”后窗口会隐藏控制栏并开启鼠标穿透。
5. 点击“功能”或右键托盘图标打开控制中心，可管理屏蔽词、搜索历史和调整实时策略。

快捷键：

- `Ctrl + Alt + D`：显示或隐藏悬浮窗。
- `Ctrl + Alt + L`：锁定或解锁（鼠标穿透后用它解锁）。

关闭按钮只会把程序收进系统托盘。需要彻底退出时，右键托盘图标并选择“退出”。

## 当前边界

- 仅支持 B站直播弹幕。
- 支持普通桌面程序、窗口化和无边框全屏；暂不处理独占全屏游戏。
- 所有原始弹幕（含用户名）写入本机 SQLite 历史库；滚动区不显示用户名。
- 滚动区实时优先：重复内容合并、高峰自动加速，超过新鲜度的候选跳过滚动但保留历史，因此不会长期积压。
- 屏蔽词忽略空格、标点和大小写；可选择被屏蔽内容是否仍保存历史。
- 滚动位置跟随显示器刷新事件和实际经过时间计算，不固定限制为 60 FPS。
- 支持 B站整条表情弹幕（`dm_type=1`）：使用弹幕包自带的图片 URL，图片失败时降级显示原始文本。目前不替换普通文本里混排的多个小表情。
- B站接口发生变化时可能需要更新客户端协议。

## 构建

```powershell
dotnet build -c Release
dotnet publish -c Release -r win-x64 --self-contained false
```
